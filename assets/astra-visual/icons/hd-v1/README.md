# Ícones Astra HD — versão 1

23 desenhos geométricos originais produzidos para este projeto, sem copiar ícones Godot. Fontes SVG de 32 unidades e PNGs RGBA transparentes de 512×512, com traços claros. A seleção verde pertence ao tema do controle e não fica gravada nos pixels do ícone.

Reproduzir: `python tools/generate-editor-hd-icons.py`, seguido de `python tools/pack-icon-atlas.py` na raiz do repositório. O catálogo mantém os IDs existentes; versões vetoriais anteriores continuam preservadas.
