# AudioVoice — ABI23 — 2026-09-30

Uma API de observação real, zero tipos de cena novos, zero stubs. AudioSource permanece authoring persistido. AudioVoice controla pedidos pelo setter existente e consulta diagnóstico SceneAudio/miniaudio. Pedido, voz, saída autorizada e som ouvido são evidências distintas.

`new AudioVoice(source.Component).Snapshot` retorna State, Cursor em segundos e OutputRunning. State espelha SceneAudio: Stopped, Playing, Paused, MissingClip, MissingListener, InvalidBus, Limit, DeviceError, InvalidPose. Cursor vem do PCM nativo na última reconciliação; leitura não avança DSP. OutputRunning espelha deviceRunning incluindo gate de foco/pausa, sempre falso em Offline. Mute, volume, distância e roteamento podem silenciar uma voz Playing.

Play/Pause/Stop usam pedidos refletidos 1/2/0, consumidos na próxima reconciliação. Play retoma voz pausada; Stop reinicia cursor. Seek não existe na API porque falta contrato no runtime. Não simulamos progresso pelo relógio C#.

Snapshot valida mundo/objeto/geração/instância/tipo antes de ler diagnóstico. Antes de reconciliação ou depois de Stop: NotRunning. Remoção estrutural pendente conserva o componente até o ponto seguro; depois de aplicada: ComponentMissing. Identidade estrangeira/obsoleta: erro GameWorld explícito. Diagnóstico retido não ressuscita componente. A validação vem do callback, sem depender de LastStatus retido por uma consulta IsAlive anterior. Host gerenciado sem IAudioVoiceAccess recebe NotSupportedException.

ABI23 acrescenta callback ao final de ScriptSceneAccess. ScriptAudioSnapshot tem 24 bytes: size/state/outputRunning/reserved u32, cursor double. Native exige tamanho exato/reserved zero; managed usa Sequential. Completeness nativa exige version23/tamanho completo, Start managed exige versão23 e sizeof(SceneAccess). Binaries22 precisam rebuild. EditorPlayScene conecta ScriptBridge::setAudio(&audio_) ao runtime real de Play e remove o vínculo no Stop.
