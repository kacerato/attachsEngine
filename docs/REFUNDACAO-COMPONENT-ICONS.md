# Ícones dos componentes Astra

Gerados com a ferramenta integrada image_gen em 09/09/2026. PNG RGBA, fontes preservadas; redução técnica pelo pack-icon-atlas.py para células de 96 px. Paleta inspirada na marca Astra inspecionada no repositório. Não foram usados SVGs como substitutos.

Destino: assets/astra-visual/icons/named/component/physics.png

Create one production raster UI icon for Astra Android game engine. Single centered object, square canvas, true transparent background with alpha, no text, no backdrop, generous 12% safe margin. A weighty beveled cube with a lime collision frame hugging its edges, slight dynamic tilt, unmistakable physics body.

## collider — 10/09/2026

Destino: assets/astra-visual/icons/named/component/collider.png.
Ferramenta integrada image_gen, sem CLI. Ícone próprio: esfera cerâmica em gaiola
lima, visualmente distinto do cubo de Corpo físico. Integrado ao catálogo e atlas
(153 entradas, 1024×1668). Saída final RGB com fundo escuro; as duas tentativas de
alpha retornaram quadriculado desenhado e foram rejeitadas. A versão usada possui
fundo escuro opaco, perceptível no cabeçalho; transparência fica como polimento
pendente, sem alegar que o arquivo contém alpha.

Prompt de geração:

Create one new raster icon for the Astra mobile engine's 'Colisor 3D' component.
Reference image is STYLE ONLY, not an edit target: match its lively sculpted white
ceramic, charcoal recesses and vivid acid lime green trim, bevels, soft dimensional
highlights, visual identity. Distinct subject from the solid cube physics body icon:
a white sphere enclosed in two thick lime green intersecting protective cage rings,
conveying collision boundary independent of mesh. Keep silhouette compact and
unmistakable at 32px, one centered object occupying 85% of a square canvas. Premium
tactile three dimensional object, slight isometric view, no text, no letters, no
watermark, no badge border. Truly transparent background and no floor, no environment.
Not flat SVG or outline line art. Preserve alpha. No copies of the cube.

Prompt final da edição utilizada:

Edit the supplied icon. The gray checkerboard is an unwanted visible background.
REPLACE EVERY BACKGROUND PIXEL WITH UNIFORM SOLID DARK CHARCOAL #1d1f1d, including
all gaps between green rings. Absolutely no checkerboard, no transparency pattern,
no grid, no floor. Keep the dimensional white ceramic sphere inside green cage,
colors and shape intact, occupy 84% of canvas, centered. The output is a square
game-editor icon on a perfectly solid dark background. Dark background, not alpha.


## Continuidade — câmera e malha, 10/09/2026

O novo catálogo usa os PNGs Astra existentes `EditorAuthorCamera` e `EditorAuthorObject` para Câmera e Malha, e `EditorAuthorMove` para Transformação. Não foram produzidos novos masters nesta rodada nem usadas as imagens ItsMagic como assets do produto. Ícones exclusivos de câmera/malha no acabamento das famílias de componentes continuam pendentes; os atuais foram reaproveitados de forma explícita. Cabeçalhos fechados usam imagem de 28 dp e uma linha de nome.
