# Integração Android aposentada

Estes dois arquivos pertenciam ao experimento de editor Godot embarcado.
Foram retirados do source set Android em 09/09/2026 após confirmar que nenhum
consumidor fora dessa dupla chamava GodotEditorProject ou GodotEditorActivity.

O build de produção não referencia este diretório, a atividade ou o AAR. Os
arquivos são somente registro da integração anterior, não uma alternativa de
editor disponível no aplicativo. Cenas/projetos pessoais não foram removidos
nem convertidos; a autoria atual usa o documento nativo da Astra.

Ferramentas e fontes vendorizadas em integrations/godot permanecem preservadas
para consulta técnica/licenças, sem entrar no APK por esta integração.
